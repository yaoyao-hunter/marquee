# marquee 大字体模式 — 手册

`--big` 让文字以大号像素字形滚动，横跨多个终端行，而不是一行普通的终端字符：
每个字素簇（grapheme cluster）映射到内嵌的[缝合像素字体](https://github.com/TakWolf/fusion-pixel-font)
（Fusion Pixel Font）中的一个字形，并用半块字符（half-block）绘制。默认放大
倍率下，一个 CJK 字符会成为一个 12 列宽、6 行高的单元格方块。

```sh
marquee "你好世界" --big
marquee "你好世界" --big --scale 2
echo "正在部署..." | marquee --big --direction right
```

本手册完整覆盖大字体模式的用法：各标志、几何尺寸、滚动行为、尺寸下限、输入、
重定向输出与退出行为。单行模式和通用规则（输入优先级、退出码、环境变量、主题）
记录在 [docs/marquee.1](marquee.1) 和 [README](../README.md) 中；除下文所述内容外，
其余行为不变。本文件是英文版 [manual.md](manual.md) 的中文译本，两者内容保持
同步。

## 开启方式

| 标志 | 取值 | 默认 | 规则 |
|------|------|------|------|
| `--big` | — | 关闭 | 启用大字体模式。 |
| `--scale N` | 1–32 | 1 | 像素放大倍率。需要 `--big`。终端必须容得下它（见下文）。 |
| `--font name` | `zh-hans` | `zh-hans` | 用哪个打包的像素字体渲染。需要 `--big`。 |

- 不带 `--big` 使用 `--scale` 或 `--font` 属于用法错误（退出码 2）：它们只在
  大字体模式下才有意义。
- `--scale` 超出 1–32，或 `--font` 不是 `zh-hans`，都是用法错误（退出码 2）。
  其他字体变体（`ja`、`zh-hant`）已规划但尚未打包；图集生成器已支持构建它们。
- `--font zh-hans` 无需显式写出——它就是默认值。

## 几何与渲染

- `--scale N` 时，每个字体像素变成一个 `N×N` 的终端单元格方块（默认
  `N = 1`），用半块字符 `█` `▀` `▄` 和空格绘制，使用主题的前景色（主题为
  `default` 时即终端默认色）。主题的背景色绘制空白单元格；纯色主题完全不
  发出颜色转义序列，所以 `--no-color` 只是强制回到它。调色盘主题（颜色列
  表）沿屏幕列铺色带，每种颜色占 `band` 个单元格，因此比色带宽的字形会
  同时显示多种颜色。
- 全宽字形（CJK、全宽标点）为 12×12 字体像素，即 `12·N` 列 × `6·N` 行
  单元格。半宽字形（ASCII 字母、数字、标点）为 6×12 像素，即 `6·N` 列 ×
  `6·N` 行。
- 字形占据 `6·N` 行：光标所在行加上其上方的各行。光标行以下不会被触碰。
- 打包的 `zh-hans` 图集覆盖：可打印 ASCII、GB2312 一级/二级汉字（约 6763
  字）、假名和全宽标点。其他字符——包括图集之外的 emoji 与生僻文字——渲染为
  同样大小的空心方框（豆腐块，tofu），滚动绝不中断。
- 字素簇作为整体映射，与单行模式的计数方式一致：由零宽连接符（ZWJ）连接的
  组合是一个单元，从簇中第一个拥有字形的码点开始渲染；若都没有字形则渲染
  豆腐块。

## 滚动行为

运动方式就是单行模式的运动方式，只是换了个绘制器；引擎是共享的，所以主模式
的所有选项在大字体模式下同样有效、含义相同，只是“列”现在按终端单元格计：

- 每帧一个列步进，由 `--speed MS`（1–10000，默认 50）或 `--fps FPS`
  （1–1000）控制节奏；两者互斥。
- `--direction left`（默认）从右边缘进入、向左离开；`--direction right`
  与之镜像。
- `--bounce` 在两端反转而不是循环折返；一个往返周期是：驶向一端、`--gap`、
  驶回、再一次 `--gap`。
- `--continuous` 把字形平铺成一条流：下一份条带跟在前一份后面，相距
  `--gap` 个空白单元格列，因此第一份进入之后屏幕就不会再空（前提是间隔
  比视口窄）。此时一个周期是流的一个节拍——条带加间隔——`--once`/`--repeat`
  按节拍计数。它与 `--bounce` 互斥。
- `--gap COLUMNS`（默认 8）是周期之间（连续模式下则是相邻两份之间）的
  空白单元格列数。
- `--once` 和 `--repeat N` 限定运行次数；同样以退出码 0 结束。
- `--align` 在大字体模式下无效（被接受，但尚未在任何模式中实现）。
- `--theme` 与 `--theme-file` 的作用与单行模式一致：主题的前景色给半块
  上色、背景色给空白单元格上色；纯色主题整帧 `6·N` 行共用同一对颜色序
  列，调色盘主题则逐色带逐行着色。

帧的宽度永远精确等于终端的列数。当视口边缘切过一个字形时，字形在该边缘被
裁剪——半个 `你` 平滑地进入和离开屏幕——因此运动绝不跳列，也不会折到下
一行。连续模式下，裁剪对流里的每一份都同样生效，各份平铺视口，既无空隙
也无重叠。

## 尺寸下限与窗口调整

大字体模式为每个缩放级别声明它需要的最小终端：视口须能容纳一整个全宽
字形，且字形行数之外还留出一行余量：

```
columns ≥ 12·N        rows ≥ 6·N + 1
```

比这更小的终端在绘制任何内容之前即被拒绝——退出码 2，提示打印在
**stderr**（stdout 保持干净，便于管道使用）：

```
marquee: the terminal is too small for --big --scale 2: needs at least 24 columns × 13 rows, this terminal is 20×12
```

运行中窗口缩到下限以下不会中断滚动：缩放按高度重新适配——窗口变小则调
低，变大则回升向请求值——字形按更窄的视口裁剪，并向 **stderr** 打印一
条提示，说明恢复运行所需的尺寸：

```
marquee: the terminal became too small for --big --scale 2: needs at least 24 columns × 13 rows, scrolling at --scale 1 until it fits again
```

尺寸变化后，下一帧立即按新宽度重绘，文字保持在行程中的同一位置。

## 输入

与单行模式完全一致：位置参数 `TEXT` 优先，stdin 永不被读取；无参数时，读取
管道 stdin 至 EOF，每行去除首尾空白、丢弃空行、其余用单个空格连接；无参数且
stdin 是终端时，marquee 以退出码 2 退出而不是阻塞等待输入。空白输入被拒绝
（退出码 2）。

## 重定向输出

当 stdout 不是终端时，每帧写成 `6·N` 纯文本行——每个单元格行一行，没有
光标定位、没有转义字节——节奏照常。此时由 `COLUMNS` 和 `LINES` 提供假定的
尺寸（默认 80 和 24），尺寸下限也照此检查：对 `--scale N` 而言过窄或过矮
的管道，会像过小的窗口一样被拒绝。如果管道的读者消失
（`marquee --big … | head -3`），marquee 静默地以退出码 0 退出，而不是报告
管道破裂（broken pipe）。

## 终端与退出行为

- 不进入备用屏幕（alternate screen）；回滚缓冲区（scrollback）保持原样。
- 光标被隐藏；每帧是一次带缓冲的写入加刷新，单元格行之间没有闪烁。
- 任何退出路径——周期跑完、Ctrl+C（在 raw 模式下读取，退出码 0）、I/O 错误
  （退出码 1）、甚至 panic——都会擦除 marquee 占用的 `6·N` 行、重新显示
  光标并退出 raw 模式，shell 提示符因此落在一个干净的行上。
- 退出码与手册页一致：0 完成 / Ctrl+C / 读者消失，1 真实 I/O 错误，2 用法
  错误。

## 示例

默认放大倍率，一个字形 = 12 列 × 6 行：

```sh
marquee "你好世界" --big
```

两倍大小——每个字形 24 列 × 12 行；任何高度不小于 13 行的终端都能放下，
无需收缩：

```sh
marquee "你好世界" --big --scale 2
```

快速滚动、输入来自管道、方向镜像、首尾相接：

```sh
echo "正在部署..." | marquee --big --fps 60 --direction right --continuous
```

带主题——半块用加粗亮绿绘制，空白不动：

```sh
marquee --big --scale 2 "ON AIR" --theme matrix
```

弹跳式广告牌，紧凑间隔，恰好三个周期：

```sh
marquee --big --bounce --gap 2 --repeat 3 " ON AIR "
```

请求超过终端能放下的放大倍率（24 行终端）：

```sh
$ marquee --big --scale 9 "hello"
marquee: --scale 9 does not fit 24 terminal rows; scrolling at --scale 3
```

纯文本帧，每次运行得到一个文件、每帧 `6·N` 行：

```sh
marquee --big --once "done" > frames.txt
```

## 已知差距

- `--align` 被接受并校验，但无效果（为静态摆放模式保留）。
- 只打包了 `zh-hans` 图集；`ja` 和 `zh-hant` 需要先提交其生成的资源。
- 暂无按模式区分的主题——同一主题以同一方式绘制单行与大字体模式；调色
  盘的色带固定在屏幕上，随文字移动的颜色（每个字符保持自己的颜色）尚不
  在主题语法之内。
- 无比例（proportional）变体、无主题语法之外的颜色、无垂直滚动——即
  `docs/big-font-mode.md` 中的 V1 范围。
